# DGStation GitHub Pages Template

Static responsive website based on the supplied DGStation reference image.

## Files
- `index.html` — main page
- `style.css` — responsive design
- `script.js` — promotions and small interactions
- `assets/dgstation-reference.png` — supplied reference screenshot
- `.nojekyll` — GitHub Pages compatibility

## Publish on GitHub Pages
1. Upload all files to the root of your GitHub repository.
2. Commit changes.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
